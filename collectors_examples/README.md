# Java Collectors Examples

This folder contains examples demonstrating Java Stream API Collectors usage.

Examples:
1. Student Result Grouping (Collectors.groupingBy)
2. Word Frequency Counter (Collectors.toMap)
3. Order Revenue Summary (Collectors.summingDouble)
4. Employee Salary Categorization (Collectors.groupingBy + averagingDouble)
5. Library Book Statistics (Collectors.summarizingInt)

Each example contains a `main` method to run a simple demo.
