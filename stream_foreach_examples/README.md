# Java Stream API & forEach() Examples

This folder contains examples demonstrating Java Stream API and forEach() usage.

## Stream API Examples
1. Top 5 Trending Movies (filter, sorted, limit)
2. Hospital Doctor Availability (filter, sorted)
3. Insurance Claim Analysis (groupingBy + averagingDouble)
4. Filtering Expiring Memberships (filter with LocalDate)
5. Transforming Names for Display (map, sorted)

## forEach() Examples
1. Stock Price Logger
2. Event Attendee Welcome Message
3. IoT Sensor Readings
4. Email Notifications
5. Logging Transactions
